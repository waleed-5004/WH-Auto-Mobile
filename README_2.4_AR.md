# WH Auto 2.4 — Live Bridge + Auto Cloud

هذه النسخة تعالج المشكلتين المؤكدتين من الاختبارات الميدانية:

1. الصفحة الرئيسية أصبحت تعتمد على BYDMate localhost webhook كمصدر Live أساسي.
2. Cloud config يُحفظ بشكل متزامن، والخدمة تبدأ تلقائياً مع تشغيل التطبيق/إقلاع النظام.

## مصدر البيانات
BYDMate يرسل إلى:
`http://127.0.0.1:8765/api/bydmate/telemetry`

WH Auto يقوم فوراً بتحليل الحقول وعرضها في الصفحة الرئيسية وحفظ آخر قراءة.

## Cloud
بعد إدخال TELEMETRY_SECRET مرة واحدة وحفظ الإعدادات، يبقى enabled محفوظاً.
AgentService يبدأ تلقائياً عند BOOT_COMPLETED وMY_PACKAGE_REPLACED، ويرفع إلى Cloudflare كل 15 ثانية أثناء الحركة/الشحن و30 ثانية أثناء الوقوف.

## Last known cache
آخر قراءة مفيدة تحفظ محلياً، لذلك بعد إعادة فتح التطبيق لا تبدأ الشاشة بشرطات إذا لم تصل packet جديدة بعد.

## أمان
المشروع قراءة ومراقبة فقط؛ لا أوامر أبواب/نوافذ/تشغيل/قيادة ولا تجاوز لصلاحيات BYD.
