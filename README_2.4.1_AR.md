# WH Auto 2.4.1 — Auto Cloud Fix

هذه النسخة تعالج الملاحظات التي ظهرت داخل السيارة في 2.4.0.

## الإصلاحات

1. **لا يوجد زر Cloud تشغيل/إيقاف يدوي بعد الآن**
   - بعد إدخال `TELEMETRY_SECRET` مرة واحدة والضغط على Save يصبح Cloud = AUTO ON.
   - يبدأ الرفع تلقائياً عند فتح WH Auto وعند إعادة تشغيل السيارة.
   - تحديث APK فوق النسخة الحالية يحافظ على الإعدادات.
   - إذا تم حذف التطبيق بالكامل أو Clear Data فسيحتاج السر إلى إدخال مرة واحدة من جديد.

2. **تحديث واجهة Cloud فور الحفظ**
   - لا تبقى الشاشة تعرض OFF/Not configured بعد الحفظ.

3. **رفع فوري لكل BYDMate packet**
   - عند وصول Webhook جديد من BYDMate يتم تحديث الصفحة الرئيسية وحفظ القراءة ورفعها للسحابة فوراً.
   - لا ينتظر التطبيق دورة الـ30 ثانية.

4. **الصفحة الرئيسية**
   - تستخدم `TelemetryStore` الذي يتحدث مباشرة من BYDMate localhost.
   - الحقول المدعومة: SOC، العداد، السرعة، القدرة، الشحن، الحرارة، ضغط الإطارات.
   - آخر قراءة تحفظ محلياً لتجنب صفحة فارغة بعد إعادة فتح التطبيق.

## ملاحظة
الـ TELEMETRY_SECRET لا يتم تضمينه داخل المشروع لحماية حسابك. أدخله مرة واحدة فقط على السيارة.
